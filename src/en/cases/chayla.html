About the project

An app for the Chayla Group restaurant chain: guests browse the menu, order, pay and collect bonuses

Challenge

  • Make ordering and payment simpler
  • Launch cashback for guests
  • Take load off the staff
  • Bring guests back more often

For the business

More repeat visits, a higher average check and stronger customer loyalty

For customers

Restaurant visits become better value, more convenient and more enjoyable

My role in the project

  • Researched guest scenarios
  • Designed the interface
  • Wrote microcopy, push notifications and promo banners
  • Designed the loyalty program and reviews
  • Managed content: photos and videos of dishes, venues and promotions; names and descriptions in Kazakh and English
  • Uploaded everything through the admin panel: up to 1,200 dishes from 17 venues of 7 brands

01

QR menu and ordering

Depending on the table status, scanning the QR code either takes the guest straight to payment or opens the online menu. No more waiting for a waiter or downloading a separate app

02

Bonus program

Cashback from 2% on every order

1 bonus = 1 tenge. Up to 50% of an order can be paid with bonuses. Reaching a new level raises the cashback

03

Reviews and tips

After paying, a guest can leave a rating, a comment and a tip for the waiter — all in one flow

04

QR payment for orders

Every table has its own unique QR code synced with the restaurant’s iiko system. Customers can pay straight from their phone, which speeds up service and reduces the chance of errors

05

Microcopy and approach

I tried to make every interaction warm, human and clear

06

Design library

→ DalaDev core design system
This project reused the core design system we had built on earlier projects

Developers simply loaded a JSON file with the updated tokens, which cut implementation time significantly

Adapting the design library:

  • Copying the Figma file with tokens, components and assets
  • Updating color tokens for the dark and light themes
  • Checking that they apply correctly in components
  • Customizing product cards for the project
  • Launching the library in a separate file for mockups

Typography and sizes stayed the same, but we tested the tokens for quick customization

As a result, adapting the interface took minimal time, and the design stayed consistent in both themes

07

Results

The project launched only recently, so it’s too early to talk about numbers. But we’re already getting the first feedback from guests and the team — they like the app, its visual style and how easy it is to use. That’s inspiring for the product’s further development!

Why I’m proud of this project

It’s not just a menu or a payment tool. It’s a digital restaurant where guests feel cared for from the very first second. I did everything I could to make every screen speak to the user in one voice
