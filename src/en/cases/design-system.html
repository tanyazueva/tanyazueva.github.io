New design system

One system for iOS, Android and Web instead of 17 libraries — so a small team can keep up with the business

Role
Senior Product Designer
My scope
Icons, components for the redesign, rules
Platforms
iOS, Android and Web

Challenge

The system was built for a large company: 17 libraries, 507 colors, and its own font and components on each platform. Four designers each worked their own way, and the product needed speed

What I did

  • Icons

    Redrew all 213 icons and wrote a guide — an agent can use it to draw and check icons

  • A sandbox for the agent

    The agent edits a copy of a component, I review it — and only then do the changes go into the library

  • Layer naming

    We agreed to give identical layers identical names: one name instead of default layer names or 3–5 variants

  • Specifications

    Documented how to build, check and hand off a component to development

  • Rules for AI

    Wrote rules Claude uses to check components before they go to development

  • Components for the redesign

    Updated 16 components and filed 48 development tasks for them

03 · Icons

Icons in one style

The icons varied in style and stroke weight. I redrew 213 icons and wrote a guide with 53 rules — stroke weight, gaps, corner radii, three sizes matched to font weight. With it, even Claude can draw new icons 😳

04 · Layer naming

Same layers, same names

The library had about 1,270 layers and 200 different names: the same heading was called text, Title or “Заголовок” (Russian for “heading”). I put together a glossary where each role has one name

Overrides don’t get lost

When you switch a component variant, Figma keeps overrides only on layers with matching names

Clear to the agent

AI agents and developers find the right layer by name

05 · Process

We dropped branches in Figma

Each stage of a task is a separate page in the file. We wrote the rules down, and both people and AI follow them

Branches mixed up versions

It was unclear where the current mockup was

Production isn’t edited by accident

The final mockup on the “In production” page is frozen — nobody touches it
