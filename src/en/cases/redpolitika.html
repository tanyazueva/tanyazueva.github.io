Editorial guidelines

An interface copy guide for the BAZAR product: voice, punctuation, numbers, money, buttons and notifications

Role
Senior Product Designer
Format
Guide in Figma
Audience
Designers, marketing, analytics, development

Challenge

BAZAR had no shared rules for interface copy. There was even an agreement on the letter ё, but nobody followed it, and screens looked inconsistent. I proposed creating editorial guidelines and built them entirely on my own

How I worked

  • Benchmark

    Studied the guides of 15 Russian brands: Ozon, T-Bank, Dodo, Kontur, Avito, Sber and others

  • Aligned with development

    Showed how non-breaking spaces work and convinced developers to copy text from Figma instead of retyping it

  • Decisions

    Where sources disagree, I picked one rule: always write “ё”, no period at the end of a block, no emoji in the interface

  • Guide in Figma

    Designed an interactive guide built on one pattern: rule → why → do / don’t examples

Before and after

How the guide changes screens

We didn’t rewrite old copy all at once. When we rework a feature, we rewrite its copy by the guide along the way. Clearly bad copy gets its own tasks

Empty subscriptions feed

“Empty states” rule: what will appear here and how to get it

Polite “you”, lowercase

“Follow authors” in the polite form instead of the casual “Go find interesting authors and subscribe”; “Для вас” (“For you”) instead of a capitalized “Для Вас”

What will appear here

“Their posts will appear in this feed” instead of “to stay up to date”

No “!”

We use exclamation marks only for congratulations and thanks

Delete post alert

“Confirmation” rule: we only ask about things that can’t be undone

Title — a question with the action

“Delete post?” instead of “Do you really want to delete this post?”

Description — what happens next

“Once deleted, it can’t be restored” instead of the stern “This action can’t be undone”

Second button — “Cancel”

“Undo” next to “This action can’t be undone” was confusing: it wasn’t clear what we were undoing

Post not found

“Errors” rule: what happened and what to do next

What happened — no guesswork

“Deleted or hidden” instead of “It may no longer exist”

What to do — a button

“Back to feed” instead of a dead-end screen

No feelings, no “!”

Removed “We hope you’ll enjoy other posts!”: we don’t attribute feelings and don’t use “!”

  • The most useful part of the project

Guidelines that Claude writes by

To use the Figma guide, you have to open it and find the rule. So I turned the guidelines into an md file for Claude — the agent knows every decision and applies it in its work

redpolitika-claude.md

## How to answer
1. Ready-to-use copy first, then the explanation
2. Rule → why → do / don’t
3. Link to the guide section: “Numbers → Time”
4. Not decided yet? Don’t make it up, ask

## Numbers
| Time | 09:00 | not 9:00 |
| Percent | 12,5% | not 12,5 % |
| Thousands | 12 500 ₽ | not 12500 ₽ |
| Deadline | through March 15 inclusive |

How it works in practice

Check the copy on the Premium subscription screen

Found 3 fixes:

“Premium for 299,00 ₽.” → “Premium for 299 ₽”

Currencies → round amount without zeros; Punctuation → period

“Valid until March 15” → “Valid through March 15 inclusive”

Numbers → Deadline

“Renews at 9:00” → “Renews at 09:00”

Numbers → Time

What’s inside

  • All decisions in “do / don’t” tables
  • Product voice: tone, apologies, jokes by channel

How it works

  • A designer asks the agent to write or check copy
  • The agent fixes it by the rules and cites the guide section
  • Doesn’t make up what isn’t decided — asks instead
  • Flags issues in old features separately, as legacy

What changed

  • No need to keep 60 rules in your head
  • Copy in mockups, tasks and specs sounds the same
  • A new decision is one line in the file, and the agent knows it right away
